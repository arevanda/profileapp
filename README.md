## 📋 Kriteria Komponen UI

Aplikasi ini memenuhi kriteria penggunaan elemen UI Jetpack Compose berikut:

- [x] **`Row`** - Menata ikon dan teks secara horizontal pada daftar informasi detail.
- [x] **`Column`** - Menata tumpukan elemen secara vertikal (Foto, Nama, NIM, dan Kartu Informasi).
- [x] **`Spacer`** - Memberikan jarak/spasi antar komponen UI secara presisi.
- [x] **`Box`** - Digunakan untuk membuat banner latar belakang dan membingkai foto profil melingkar.
- [x] **`Text`** - Menampilkan nama, NIM, label, dan informasi kontak/detail profil.
- [x] **`Modifier`** - Mengatur ukuran (`size`, `fillMaxSize`, `fillMaxWidth`), *padding*, warna latar belakang, bentuk (*shape*), border, serta alignment.
- [x] **`Icons`** - Menggunakan Material Icons (`Person`, `School`, `Email`, `Phone`, `LocationOn`).
